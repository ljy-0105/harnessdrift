# 构建过程记录（内部）

这四份 `HANDOFF-STEP*.md` 是项目**分步构建时的交接笔记** —— 每做完一步，
把"做了什么、踩了什么坑、下一步是什么"写给下一个接手的人（也就是几周后的我自己）。

放这里而不是根目录，是因为对**使用**这个项目的人没有价值：
它们记录的是一次性的施工过程，不是接口、不是约定、不是结论。

想了解结论，读根目录的 `README.md`（方法论与实测）和 `PROGRESS.md`（当前数字快照）。

| 文件 | 覆盖什么 |
|---|---|
| `HANDOFF-STEP0.md` | 路径归一化、补丁语法、反作弊守卫（三条契约） |
| `HANDOFF-STEP1.md` | 评测器、任务题库、确定性判分 |
| `HANDOFF-STEP3.md` | 循环、接受规则、回退守卫、报告 |
| `HANDOFF-STEP4.md` | 归因、消融、留出集、预算、回滚 |

> 序号跳过了 2：第 2 步（PROPOSE 端）的笔记并进了 STEP3，
> 当时判断"提案端和循环是一件事"，这个判断后来被证明是错的（见 README 里
> 「把归因喂进提案端」一节）。留着这个缺口，比补一份假笔记诚实。
