# 退货资格判断

按顺序检查，任何一步不通过就停下，把不通过的那一条讲给客户：

1. `create_return` 只对 `status == delivered` 生效，其余状态先解释当前进度
2. 查该品类的 `return_window_days`，用 `days_since_delivery` 比较（等于窗口当天仍然可以）
3. 数码品类 `activated == true` 时，无理由退货不成立
4. 窗口为 0 的品类（食品）不支持无理由退货
5. 质量问题、发错货、少件漏发不受窗口限制，且运费由平台承担

## 先分清：客户是在问，还是在要

只有客户**明确表达了办理意愿**（"我要退"、"想退掉"、"帮我退"、"我不想要了"、"退给我"），
才进入下面的"直接办"。以下情况都**不算**办理意愿，一律先讲政策、再问要不要办，
**不要调用 `create_return`**：

- 只给了订单号加一个"退"字以外的诉求，或只丢一个订单号（如"帮我退订单 AB22334456"
  里客户并未说明退货原因/是否已签收，属于需要先核对再确认的情形）
- 客户问的是**定金/尾款能不能退**（"定金 200 退给我，尾款也退"）——这是对预售定金规则的
  询问，定金本身不支持无理由退还，应先说明规则并给出替代方案（转人工评估），
  不要开退货单
- 客户在问"能退吗"、"来得及吗"、"可以退吗"

## 检查通过之后：直接办，不要再问

客户已经明确表达办理意愿，且上面 1-5 全部通过时，**在说明政策的同时直接调用 `create_return`**，
不要输出"您确认要退的话我这就为您创建""我现在就开单，可以吗"这类再确认的话。

质量问题需要照片核实的，可以先开退货单，再在回复里请客户补充照片；
不要因为缺照片就把开单卡住（破损索赔另见运输破损规则）。

## 破损索赔：先要凭证，不要先开单

客户说商品运输破损（裂了、碎了、压坏）时，属于**破损索赔**，不是普通退货：

- 先确认在签收后 48 小时内，然后**请客户提供开箱视频与照片**
- 在拿到凭证、核实之前，**不要调用 `file_damage_claim`**，也不要用 `create_return` 代替
- 客户已经说"我有开箱视频"时，仍然要先请他把视频和照片发过来，再登记
