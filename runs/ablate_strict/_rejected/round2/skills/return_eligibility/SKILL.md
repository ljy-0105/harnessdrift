# 退货资格判断

按顺序检查，任何一步不通过就停下，把不通过的那一条讲给客户：

1. `create_return` 只对 `status == delivered` 生效，其余状态先解释当前进度
2. 查该品类的 `return_window_days`，用 `days_since_delivery` 比较（等于窗口当天仍然可以）
3. 数码品类 `activated == true` 时，无理由退货不成立
4. 窗口为 0 的品类（食品）不支持无理由退货
5. 质量问题、发错货、少件漏发不受窗口限制，且运费由平台承担

## 先确认「这件商品本身能不能退」，再谈窗口

上面 1-5 只回答「时间上还来不来得及」。在开单之前，还要确认**这件商品属于可退范围**：

- 预售商品：**定金不支持无理由退还**。客户要退定金时，不能靠开退货单来解决，
  定金部分只能说明规则（有异议转人工评估）。
- 定制类、生鲜类、已拆封的猫砂等消耗品、标注「不支持无理由退货」的商品：
  非质量问题不支持退货，不要开单。
- 客户要退的商品里**包含定金**时，先判断定金能不能退；定金退不了就**不要开退货单**，
  只把规则讲清楚（尾款/货款部分怎么处理一并说明）。

换句话说：**开退货单 ≠ 解决所有退款诉求**。定金、价保差价这类诉求没有对应的开单动作，
属于「只回答、不执行」。

## 检查通过之后：直接办，不要再问

客户已经明确表达办理意愿（"我要退"、"想退掉"、"帮我退"、"我要退，别跟我扯那些规定"），
且上面 1-5 全部通过、商品也在可退范围内时，**在说明政策的同时直接调用 `create_return`**，
不要输出"您确认要退的话我这就为您创建""我现在就开单，可以吗"这类再确认的话。

只有客户是在**询问**（"能退吗"、"来得及吗"）时，才先讲政策再问要不要办。

质量问题需要照片核实的，可以先开退货单，再在回复里请客户补充照片；
不要因为缺照片就把开单卡住（破损索赔另见运输破损规则）。

## 破损索赔：先要凭证，不要先开退货单

客户说商品运输破损（裂了、碎了、压坏）时，走的是**破损索赔**流程，不是普通退货：

- 先确认在签收后 48 小时内，然后**请客户提供开箱视频与照片**，核实后再登记补发或退款。
- 客户说"我有开箱视频"但还没发过来，仍然属于**缺凭证**，要请客户发过来，
  不要在这一步就调用 `file_damage_claim`，也不要开退货单。
- 破损索赔的运费由平台承担，回复里说明即可。
