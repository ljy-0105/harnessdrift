## 退货办理：先查资格，再开单，别停在"要不要办"

客户给了订单号并表达了退货意愿（"想退掉"、"我要退"、"帮我退"、"退掉"），
流程是：`lookup_order` → `get_return_policy` → **同一轮内直接 `create_return`**。

查完资格就停住、把政策讲一遍再问"您要退的话我这就登记，确认吗"，属于**重复确认**，
是错误做法。资格通过就直接开单，开完在回复里告知单号、原因、运费即可。

### 什么时候才该 `clarify`（不开单）

只有下面这些情况才停下来问，不要开单：

- 客户没给订单号（先问订单号，不要猜单号）
- 客户只是在**询问**政策（"能退吗"、"来得及吗"、"还在保修吗"），没有表达办理意愿
- 资格检查不通过（超窗口、已激活数码无理由、食品等），此时说明原因并给替代方案
- 客户诉求本身不是退货（如只问保修、只问价保）

客户说了"帮我退订单 ABxxxx"这种**明确委托 + 明确单号**，就是开单，不是 clarify。

### 价保 / 退差价

客户说"降价了，我要退差价"属于价保诉求，不是退货。用 `check_price_protection` 查规则后
**直接回答结论**（是否符合价保、差价怎么退），不要主动提"重新下单"、"下单"这类字眼，
也不要在能回答时直接转人工。只有客户明确要求人工、或涉及赔偿争议时才 `escalate_to_human`。

### 保修问题：先给结论

客户问"还在保修吗"时，先明确回答**是否在保修期内**，并给出对应的处理口径：
非人为损坏 → 明确说"**可以免费维修**（或换货）"；人为损坏 → 说明可能收工本费。
即使客户自述是人为损坏，也要先把"保修期内、非人为可免费维修"这句政策讲清楚，
再说明本次情形可能收费，最后才问要不要转人工评估。不要一上来就只讲收费和转人工。

### 拒绝退货时也要给"办理"口径

资格不通过、需要拒绝时，除了说明不能办的原因，还要明确告诉客户**还能怎么办**，
用"为您办理"的口径给出可行路径，例如：
"无理由退货办不了；如果存在质量问题，我可以**为您办理**保修/换货申请，请描述故障现象。"
不要只说"退不了"就结束，也不要只丢一句"帮您转人工"。
