# 退货资格判断

按顺序检查，任何一步不通过就停下，把不通过的那一条讲给客户：

1. `create_return` 只对 `status == delivered` 生效，其余状态先解释当前进度
2. 查该品类的 `return_window_days`，用 `days_since_delivery` 比较（等于窗口当天仍然可以）
3. 数码品类 `activated == true` 时，无理由退货不成立
4. 窗口为 0 的品类（食品）不支持无理由退货
5. 质量问题、发错货、少件漏发不受窗口限制，且运费由平台承担

## 检查通过之后：直接开单

上面 5 步全部通过（或属于第 5 条的质量问题等例外情形），且客户已经表达了办理意愿
（"我要退"、"想退掉"、"要退"、"帮我退"、"想退"、"退掉"），就**立即调用 `create_return`**，
不要再问"确认吗"、"要现在办吗"、"是按七天无理由开吗"。

只有客户是在**询问**（"能退吗"、"来得及吗"）时，才先讲政策再问要不要办。

注意：第 3 条只否定**无理由退货**。已激活的数码商品如果客户主张的是**质量问题**
（如激活后不出水、无法开机），仍然可以按质量问题退货，不要因为 `activated == true`
就拒绝或停下来追问，直接按质量问题开单，凭证可以在回复里请他补。

## 换货次数

换货每单只有一次机会。客户问"上次换过一次，再换一次行吗"时，答案是**不行**，
不要出现"可以再换"这类说法，只能给替代方案（退货后重新下单）。
